# Image Analyzer

## Project Overview

Image Analyzer is a Python-based application developed using Object-Oriented Programming (OOP) principles. The application performs various image processing operations such as loading, resizing, grayscale conversion, edge detection, image information extraction, and saving processed images.

The project emphasizes modular programming, exception handling, loops, and Python built-in functions while processing image files.

---

## Objectives

- Learn Object-Oriented Programming in Python.
- Implement modular code using functions.
- Process image files using OpenCV.
- Handle runtime errors using exception handling.
- Build a user-friendly menu-driven application.

---

## Features

- Load an image
- Display image information
- Resize image
- Convert image to grayscale
- Blur image
- Detect edges
- Rotate image
- Flip image
- Save processed image
- Handle invalid image files using exception handling
